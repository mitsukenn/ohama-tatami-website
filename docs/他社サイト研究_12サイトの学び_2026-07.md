# 日本の代表的サイト12本の研究 → 大浜畳商店への学び（2026-07-08）

調査方法：6エージェント並列で12サイトを実地取得・観察（Fable 5監修）。観察は事実ベース、推測は明記。
対象：虎屋／中川政七商店／土屋鞄製造所／星野リゾート界／北欧、暮らしの道具店／茅乃舎／ドモホルンリンクル（再春館製薬所）／世田谷自然食品／くらしのマーケット／ホームプロ／ジャパネットたかた／やずや
選定基準：ペルソナ分析（P1=68歳法事前・P2=35歳ママ・P3=54歳県外実家管理）の課題に対応する「日本の名手」。

---

## 0. 最大の発見：大浜はすでに「一流の型」を多数実装済み

答え合わせから言うと、**日本の代表的サイトがやっている信頼パターンのかなりの部分を、大浜サイトはすでに持っている**：

| 一流サイトの型 | 大浜の現状 |
|---------------|-----------|
| ホームプロ「契約する義務はありません」 | ✅「お見積もり後のお断りも歓迎します」 |
| くらしのマーケット「24時間以内の返信」表示 | ✅「LINEは24時間受付・返信は営業時間内」（今週実装） |
| 再春館「CTA直下でFAQ即答」 | ✅ FAQ「いいえ、かかりません。」の断言 |
| 北欧、暮らしの道具店「記事末の固定導線」 | ✅ 全記事共通のarticle-cta |
| ホームプロ「実績数値の帯」 | ✅「数字で見る大浜畳商店」6カード |
| 世田谷「はじめての方へ」 | ✅ hajimete記事・flow.html |

つまり大浜は「変な位置」にいない。ここから先は**差分だけを取りに行けばいい**。以下、まだ持っていない学びを効果順に。

## 1. 電話の壁の外し方（P1の「最後の1cm」に直効）

### 1-1. 第一声の台本を渡す【やずや】★★★ 即実装可
> 「お電話の際は『ホームページを見た』とお伝えください」

「何と言えばいいか分からない」問題を丸ごと解決する日本の通販の知恵。大浜版：**「お電話では『ホームページを見た』とだけお伝えください。あとはこちらから順にお伺いします。」**——感情遷移分析で特定した「電話の第一声の壁」への処方が、実在の一流企業で実証されていた。

### 1-2. 「誰が出るか」を明示する【再春館「お客様プリーザー」】★★★ 🔍要確認
再春館は応対者に呼称を与えて「知らない会社への電話」を「プリーザーさんへの相談」に変えている。大浜版：**「お電話には三代目の大浜が直接お受けします」**——コールセンターには構造的に不可能な、店主の顔が見える店だけの武器。※実際に本人が出る運用か大浜さん確認。

### 1-3. 番号の脇に「用件の例」を置く【ジャパネットの窓口分離の応用】★★
「お見積もりのご相談／日程のご相談／畳の状態を見てほしい——どれでもどうぞ」。かける前に用件が定義されると第一声の不安が消える。

### 1-4. 電話番号には毎回、受付時間をセット表記【やずや】★★ 即実装可
やずやは掲載箇所ごとに「通話料無料・受付時間」を毎回反復。大浜も電話番号が出る全箇所に「8:30〜17:00・日祝休（土曜不定休）」を徹底セットで。「かけ直しの徒労」を防ぐシニア配慮。

## 2. 透明性の技術（「コミコミ」と言わずに同じ安心を作る）

### 2-1. 「この料金に含まれるもの」の列挙【くらしのマーケット】★★★ 🔍要確認
くらマの畳カテゴリは「畳縁のサンプル用意（3種類以上）」「畳の運び出し」「畳下の掃除」まで必須作業として明文化。金額でなく**作業の定義**で透明性を作る——NGワード「コミコミ」を使わずに同じ効果を出せる合法手段。大浜の料金表直下に「この料金に含まれるもの」リストを（実際に行っている工程のみ。大浜さんに工程リストの確認）。

### 2-2. 個人情報の「開示タイミングの線引き」【ホームプロ】★★★ 即実装可
「現地調査を依頼するまでは匿名のまま」——いつ名乗るかの明示が「渡した瞬間に営業が始まる」不安を外す。大浜版：**「お写真と畳の枚数だけでお見積もりできます。お名前・ご住所は、日程を決める段階で伺います。」** LINEは名乗らず始められる——この構造的利点を明文化して価値にする。

### 2-3. 「無料の理由」を開示する【再春館「お試しセットをご用意する理由」】★★★
無料＝裏があるのでは、を動機の開示で外す。大浜版：**「LINEお見積もりを用意している理由——畳は現物を見ないと正確な金額が出ません。だからこそ先に概算をお伝えして、金額を見てから決めていただきたいのです。」**——大浜の誠実経営そのものの言語化。line-mitsumori.htmlの冒頭に。

### 2-4. 「できないこと」を同じ分量で書く【くらマ補償・世田谷の不利注記】★★
「畳床の傷みが激しい場合は表替えでは直りません」「畳表の日焼けは完全には防げません」——不利な事実の正直な開示が書いてある全部の信憑性を上げる。大浜のNGルール（誇張禁止）を**弱点から武器に転換する書き方**。

## 3. 格の作り方（75年を「言わずに伝える」）

### 3-1. 歴史は形容詞を削って4文で【虎屋】★★★
五世紀の虎屋の歴史本文は実質4文。年号と固有名詞だけ。「格は自分で言うと壊れる」。→ 6/17ヒアリング予定のabout強化（三代の物語・産地ストーリー）の設計指針：**形容詞を削り、検証可能な事実（年号・枚数・道具の年数）だけで組む。深掘りは段階構造（要約4文→年表→エピソード）に。**

### 3-2. 小さく具体的な数字が謙虚さの証明になる【土屋鞄「11坪・27歳」】★★★
「1965年、27歳で自宅内11坪の作業場から創業」——小ささの開示が格を作る。大浜の三代の物語にも「初代が始めた頃の工房の広さ」「今も使う道具の年数」のような**小さい数字**を掘り起こす（6/17ヒアリング項目に追加推奨）。

### 3-3. 歴史をフッターに敷く【中川政七商店】★★★ 即実装可
中川政七は創業の一文をフッターに置き、どのページから入っても信頼の土台が目に入る。大浜のフッターには現在、社名・住所・営業時間はあるが**「創業75年・三代」の一文がない**。→ 全ページフッターに「創業75年・三代続く長崎の畳店（産業廃棄物収集運搬業許可 第012410号）」を1行追加。コラム90本の記事下すべてに自動で信頼が敷かれる。

### 3-4. 歴史を未来向きに語る【中川政七「300年かけてつくりあげた」】★★
「創業75年」→「**75年かけて覚えてきた畳の仕事を、これからの長崎の暮らしに。**」古さ＝保守ではなく、続いてきた＝これからも続く（P3の「この店は先も面倒を見てくれるか」に直答）。

### 3-5. サービスに名前を付ける【星野リゾート「ご当地楽」】★★
名付けは誇張ではなく定義。「LINE写真見積もり｜畳の写真を送るだけで、職人が概算をお返しします」のように**固有名＋一行定義**の型に。「困難→工夫」の三代史【中川政七History】も同じ流れで。

## 4. 入口と遷移の設計（読み物→相談への橋）

### 4-1. 「まずは◯◯だけ」の極小ステップ【茅乃舎「まずは大根を煮て」】★★★
買ってくださいの前に、失敗しようのない小さな一歩。大浜版：**「まずは畳の写真を1枚。部屋全体でなくても、色が変わった角の一枚で大丈夫です。」**——P1の「何を撮ればいいか分からない」を撮るものの限定で外す。

### 4-2. 場面別の入口タブ【世田谷「60代女性〜」】★★★
シニアは商品名でなく「自分ごと」のラベルから入る。大浜版：**「法事・お客様を迎える前に」「子育て中のご家庭に」「県外から実家の畳を頼みたい方へ」**の場面別入口——奇しくも新規50記事の設計（jikka-tatami／nenmatsu-oyakoukou等）がこの器の中身になる。

### 4-3. 「小さく試せる」を正規メニューに【世田谷の初回限定・半月分】★★ 🔍要確認
「1部屋だけ」「1枚だけの表替え」を料金ページに正規メニューとして明記——無料お試しセットの畳店版。※小さい仕事を歓迎する方針か大浜さん確認。

### 4-4. 連載名で記事を編集物に変える【北欧・土屋鞄】★★
【畳替えの前に読む話】【三代目の作業場から】のような連載名を冠すると、90本の記事群が「寄せ集め」から「編集されたメディア」に変わる。タイトルには「表替え」等の具体語を「」で。

## 5. 写真と光（デザイン方向書と合流）

### 5-1. 光を主語にしたコピー【星野リゾート界】★★
「二つの内湯に色鮮やかな光が踊り…」——和空間の暗さを光の描写で明るく転換。大浜版：**「張替えたての畳表は、朝の光をやわらかく返します。」** 感覚語×数字の対（「い草の香りは約1ヶ月」※事実確認要）も同じ型。→ デザイン方向書「晴れた日の畳の間」の写真補正と言葉の両輪になる。

### 5-2. 写真の文法を二分する【土屋鞄】★★
情報の写真（料金表・畳の種類＝明るい均一光の物撮り）と感情の写真（職人・工房＝環境光の大判）を混ぜない。横内さんプロ写真の配置設計にそのまま使える。

## 持ち帰ってはいけないもの（不適合の明記）

- **再春館「リピート率94%」型の強い実績数値訴求** → 大浜には測定体制がなく、数字の誇示は方針とも不一致。「当店調べ」脚注の作法だけ借りる
- **くらマ「最高1億円補償」型の制度訴求** → 制度がないものは書かない。「事実の構造化」（安心のお約束3〜4点）だけ借りる
- **ジャパネットの賑やかなトーン** → 老舗の格と不一致。「ご相談併記」「電話の安全網」の構造だけ借りる
- **北欧の「記事中で一切売らない」完全コピー** → 大浜は地域サービス業。現行の記事末固定CTAとの両立（すでに達成済み）が正解
