# 【作業依頼】ブログサムネイルの比率を 16:9 に統一

作成日：2026-06-09 ／ 実行：別セッション（`tatami-site-updater` スキルを使用）
背景調査：本番 mobile-preview 実測（[[ohama-blog-thumb-display]]）／好み・NG：[[ohama-image-taste]] ／ プレイブック：`AI画像_運用プレイブック_2026-05.md`

## 🎯 ゴール
ブログサムネが**3つの表示場面でバラバラの比率に切られている**問題を解消する。
**元画像・表示枠(CSS)の両方を 16:9 に統一**し、全場面でトリミングゼロ（全体表示）にする。ついでに記事別OGPにも転用する。

### 現状（本番実測・スマホ390px）＝バラバラ
| 場面 | 表示枠 | 比率 |
|---|---|---|
| A. トップ「お役立ちコラム」(`index.html` #guide) | 120×100 | 1.2:1 |
| B. コラム一覧 (`blog/index.html`) | 311×220 | 1.41:1 |
| C. 記事下「関連記事」(`blog/*/index.html`) | 90×90 | 1:1（正方形） |

→ 元画像も 16:9(1376×768) と 正方形(1024²) が混在。**枠も画像も16:9へ統一**する。

## ✅ 決定事項
- **統一比率：16:9**
- **元画像の標準：1200×675px、`webp`（表示用）＋ `jpg`（OGP/フォールバック用）**。`<picture>`構成は現状踏襲。
- 旧画像は `images/blog/old/` に退避（既存ルール）。

---

## 変更① CSS：表示枠を3箇所とも16:9に
> ⚠️**実装上の罠**：A・Cの横型カードは `display:flex`（既定 `align-items:stretch`）なので、サムネが**カード高さに引き伸ばされる**（Cが90×90正方形に見えるのはこのため）。**`align-self:flex-start` を付けて伸びを止める**こと。Bは縦型カードなので不要。

### A. `index.html` の `.blog-thumb`（トップのコラム）
- `height: 100px;` を削除 →  `aspect-ratio: 16 / 9;` を追加、`align-self: flex-start;` を追加
- 結果：120×67.5px（16:9・全体表示）。他のプロパティ（background/border-radius等）は維持。

### B. `blog/index.html` の `.blog-list-thumb`（一覧）
- `height: 220px;` を削除 → `aspect-ratio: 16 / 9;` を追加
- 結果：全幅×(幅×9/16)（例 311×175px・全体表示）。`.blog-list-thumb img { object-fit:cover }` は維持。

### C. `blog/*/index.html` 全記事の `.related-thumb`（関連記事）
- `min-height: 80px;` を削除 → `aspect-ratio: 16 / 9;` を追加、`align-self: flex-start;` を追加
- 結果：90×50.6px（16:9・全体表示）。`.related-thumb img { object-fit:cover }` と中央寄せ(emoji fallback用)は維持。
- ※ 全記事（約57ファイル）にインライン`<style>`で同じ定義がある → **スクリプトで一括置換**。
- ※ 併せて各記事の**メディアクエリ内に `.related-thumb`/`.blog-list-thumb` の高さ上書きが無いか**grepし、あれば同様に修正。

## 変更② 画像：全サムネを 16:9 / 1200×675 に標準化
- 対象：`images/blog/blog_<slug>_thumb.*` 全点。
- 16:9でないもの（正方形1024² 等）は **被写体が切れないよう中央〜上寄りでクロップ**して16:9化。
- 出力：`1200×675` の **webp（主）＋ jpg（OGP用フォールバック）**。
- 旧版は `images/blog/old/` へ退避。`<picture>` の `srcset`/`src` 拡張子を実ファイルに合わせる。
- **新規3枚を該当記事に割当**（`Downloads/大浜畳商店_画像/ブログ用画像/` の新ChatGPT画像）：
  - 6畳総額 → `blog_6jou-cost_thumb`／長崎相場 → `blog_nagasaki-cost_thumb`／5つの方法 → `blog_cost-save_thumb`
  - これらは現状 3:2(1536×1024) → **上下を少しクロップして16:9(→1200×675)**。文字は中央寄りなので軽微なクロップで収まる（[[ohama-blog-thumb-display]] のセーフゾーン方針）。

## 変更③ ついで直し（同じ依頼でまとめて）
1. **関連記事の画像使い回しを是正**：例 `blog/6jou-cost/` の関連3枚が全部 `blog_cost_thumb` → 各リンク先記事の正しいサムネに差し替え。全記事スキャンして同様の使い回しを修正。
2. **記事別OGP**：各 `blog/*/index.html` の `og:image`／`twitter:image` を、**共通 `images/ogp.jpg` → その記事自身の16:9サムネ（絶対URL・jpg）**に変更（16:9化で初めて転用可能に）。`twitter:card` は `summary_large_image` を維持。
3. **旧サムネ刷新の確認**：現行は¥コイン＋焼き込み文字が多い（[[ohama-image-taste]] のNG）。差し替え対象として洗い出す（本依頼で全部作り直すか、優先記事のみかは要相談）。

## 作業手順
1. `tatami-site-updater` スキルを起動。
2. 変更①（CSS）→ ②（画像）→ ③（OGP・使い回し）の順で実施。1ファイル/1スクリプトずつ。
3. **FTPデプロイ**（ホスト等はメモリ `ftp_credentials.md` / CLAUDE.md 参照。`-k` 必須）。
4. **検証：`mobile-preview` で A・B・C の3場面**を390pxで撮影し、**全場面でサムネ全体が出ている（切れていない）**ことを確認。
5. OGPは1記事をシェアプレビュー（または `<meta>` の値）で確認。

## 検収チェック
```
□ A/B/C すべて 16:9 枠で表示され、画像が切れていない（mobile-preview実測）
□ A・Cのサムネが flexで縦伸びしていない（align-self:flex-start 効いている）
□ 元画像が全点 1200×675 webp(+jpg)、旧版は images/blog/old/ に退避
□ 関連記事のサムネが各記事固有になっている（使い回し解消）
□ og:image が記事別になっている（任意：今回やるなら）
□ 新規3枚（6jou-cost / nagasaki-cost / cost-save）が16:9で適用済み
□ FTPデプロイ後、本番URLで全場面 HTTP200・表示OK
```
