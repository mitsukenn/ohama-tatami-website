## 0. 最重要の発見：「答えはすべてある。だが感情のピークとすれ違っている」

実見して分かったこと。行動直前の不安への回答は、**ほぼ全てサイト内にすでに書かれている**：

| 行動直前の不安 | 回答の所在（実在確認済み） |
|---------------|--------------------------|
| 写真ってどう撮ればいいの？ | line-mitsumori.html「かんたん2ステップ」＋写真の送り方 |
| 夜中にLINE送っていいの？ | contact.html「24時間受付、返信は営業時間内に行います」 |
| 電話して出なかったら気まずい | contact.html「作業中で出られない場合は折り返します」 |
| 見積もりが高かったら断りにくい | flow.html STEP3「『思っていたより高い』と感じられた場合は、グレードの調整などもご相談いただけます」 |
| やり取りを他人に見られたくない | line-mitsumori.html「1対1のトークなので、内容が他のお客様に見られることはありません」 |
| どれを選べばいいか分からない | price.html 金バッジ「迷ったらコレ」 |

ところが、**感情が頂点に達する場所（トップ最終CTA・記事末CTA・追従バナー）のLINEボタンは、すべて lin.ee へ直行**する。つまり主要な行動導線は、これらの安心情報を**一度も経由しない**。contact.html や line-mitsumori.html まで自力でたどり着いた慎重派だけが読める構造になっている。

**遷移設計の課題は「コンテンツ不足」ではなく「配置」。感情のピーク地点に、既存の安心の言葉を運ぶことがすべて。**

## 3. 遷移の処方（ページを増やさず、動線に「回答」を運ぶ）

優先度順。いずれも既存文言の**移植**が主で、新規コンテンツはほぼ不要：

1. **主要CTA（トップ最終・記事末・追従バナー）に安心2行を同梱**
   「ボロボロの畳の写真ほど、大歓迎です」「24時間受付・返信は営業時間内」——lin.ee直行の手前に、contact/line-mitsumoriの言葉を運ぶ。※「大歓迎」の文言トーンは大浜さん確認推奨
2. **LINEボタンの飛び先の再考**：迷いの強い場所（トップ最終CTA）は lin.ee 直行ではなく line-mitsumori.html 経由も検討（「写真の送り方」を見せてから友だち追加）。即断層向けの追従バナーは直行のまま＝**二段構え**
3. **flow.html STEP3の一文をpriceに移植**：「高いと感じたら調整相談OK」は料金の緊張の谷（P1感情50）にこそ必要
4. **トップ or toujitsu要素の1行**：「工事当日はお出かけ・在宅どちらでも」（P2の未回答）→トップの流れセクションに1行
5. **遠隔手配ブロック**（P3）：「県外にお住まいのご家族からのご依頼も承ります」をabout＋contactに1行→8月の新記事2本と相互リンク。※運用実態は大浜さん確認事項#5
6. **aboutの顔写真**（DSC00835）と**Google口コミ接続**（GBP claim）は遷移全体の土台強化として既定路線を進める
