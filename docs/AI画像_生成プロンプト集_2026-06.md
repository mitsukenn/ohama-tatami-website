## 使い方

- 各プロンプトは**単体で完結**（共通ルール込み）。コピペして**最大10枚まとめて**生成OK。
- 「」内の文字は**そのまま正確に**焼き込む。**送り仮名は「お見積もり」で統一**。
- **人物は描かない**（本人の似顔絵が用意でき次第、後から差し込む方針）。
- 横長＝landscape（例 1536×1024）、縦長＝portrait（1024×1536）。元の16:9にしたい時は生成後に上下を少しトリミング。
- 生成後は下部の「採用前チェック」を通してから採用。


**描かない（禁止）**
```

実在しない人物・職人風の男性・顔や手のアップを出さない（人物は描かない）。

```
