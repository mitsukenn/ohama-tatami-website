## 参考：中平個人タクシーさんで検証済みの知見

別のクライアント（長崎の個人タクシー）でコラム戦略を実践中。そこで得た知見：

### 質の高い記事の7つのチェック項目
1. 検索意図に最初の3行で答えているか？
2. タイトルで「読みたい」と思わせるか？
3. その人だからこそ書ける情報が入っているか？（最重要）
4. 読者の悩み→共感→解決の流れになっているか？
5. 具体的な数字・固有名詞があるか？
6. 電話番号/LINEへの導線（CTA）があるか？
7. 関連記事・サービスページへの内部リンクがあるか？

### 毎日投稿 vs 週2-3本
- 毎日投稿より「週2-3本の質の高い記事」の方がSEO効果は高い
- Googleは量より質を重視
- 畳のテーマは範囲が限られるため、毎日投稿はネタ切れリスクあり
