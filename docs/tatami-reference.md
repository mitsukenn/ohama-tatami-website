## 1. 畳の構造

畳は **畳表（たたみおもて）**・**畳床（たたみどこ）**・**畳縁（たたみべり）** の3つの部材で構成されている。

### 1-1. 畳表（たたみおもて）

- 畳の表面を覆う部材。経糸（たていと）にい草を織り込んで作られる。
- 経糸の素材には **綿糸** と **麻糸** があり、麻糸の方が丈夫で高級品に使用される。麻と綿の混合（麻綿W）もある。
- い草は長さ100〜150cm程度で、長くて太さが均一、色の良いものほど高級品に使われる。
- い草は根元と先端を除いた中央部分が最も品質が良く、長いい草ほどこの良質部分を多く使えるため、上質な畳表となる。
- い草は1番草（最長・最高品質）から7番草まで選別され、等級に応じた畳表に織られる。

### 1-2. 畳床（たたみどこ）

畳の芯に当たる部分で、畳の厚さの大部分を占める。畳の断熱性・防音性・クッション性を左右する最も重要な構造部材。

| 種類 | 素材 | 特徴 |
|------|------|------|
| **藁床（わらどこ）** | 稲わらを約40cmの厚さに積み重ね、約5cmに圧縮して縫い上げる | 湿度調節機能、防音性、防火性、断熱性、耐久性、復元力に優れる。足あたりが最も良い。重量があるため薄い床には不向き。 |
| **藁サンド床** | 藁とスタイロフォームの組み合わせ | 藁床に近い質感を保ちつつ、軽量化を実現。湿度に強く断熱性あり。カビ・ダニの発生を抑制。 |
| **建材床I型** | インシュレーションボードのみ | ダニ発生率が低い。加工しやすく耐久性に優れ、現在の主流。 |
| **建材床II型** | インシュレーションボード＋スタイロフォーム（下層） | 湿気が多い床下に有効。 |
| **建材床III型** | インシュレーションボード＋スタイロフォーム＋インシュレーションボード（サンドイッチ構造） | 一般的な戸建住宅に多く採用。 |

- 仕上がり厚さは一般的に30〜55mm程度。薄畳は25mm以上で対応可能。

### 1-3. 畳縁（たたみべり）

- 畳の長辺（幅方向）に縫い付ける布製の帯状素材。
- 畳表の端を保護・補強し、型崩れやほつれを防止する役割がある。
- 素材は綿・麻・化学繊維・正絹など。柄・色のバリエーションが豊富。
- 縁なし畳（琉球畳など）も近年は人気がある。

## 2. 畳替えの種類

畳のメンテナンスには3つの段階があり、状態に応じて適切な方法を選ぶ。

### 2-1. 裏返し（うらがえし）

| 項目 | 内容 |
|------|------|
| 内容 | 畳表を裏返して再利用する。畳縁は新しいものに交換。畳床はそのまま。 |
| 目安時期 | 新畳から **約3〜5年** |
| 条件 | 裏面がきれいな状態であること。日焼けや汚れがひどい場合は裏返しできないことがある。 |
| 特徴 | 最も経済的な方法。1枚の畳表を両面使える。 |

### 2-2. 表替え（おもてがえ）

| 項目 | 内容 |
|------|------|
| 内容 | 畳表と畳縁を新品に交換する。畳床はそのまま再利用。 |
| 目安時期 | 新畳から **約7〜10年**（裏返し済みの場合は裏返しから約5年） |
| 条件 | 畳床が健全であること。 |
| 特徴 | 畳床を活かしつつ表面を一新できる。コストと仕上がりのバランスが良い。 |

### 2-3. 新畳（しんたたみ）/ 新調

| 項目 | 内容 |
|------|------|
| 内容 | 畳表・畳床・畳縁のすべてを新品に交換する。 |
| 目安時期 | **約15〜20年** |
| 条件 | 畳床が凹んだり、弾力がなくなった場合。歩くとブカブカする場合。 |
| 特徴 | 最もコストがかかるが、完全にリフレッシュできる。 |

### メンテナンスサイクルの目安

```
新畳 → (3〜5年) → 裏返し → (5年程度) → 表替え → (5年程度) → 裏返し → ... → (15〜20年) → 新畳
```

## 4. 畳のサイズ規格

日本の畳は地域の建築文化により異なるサイズ規格が存在する。

| 規格名 | 1畳のサイズ（約） | 主な使用地域 | 備考 |
|--------|-------------------|-------------|------|
| **京間（きょうま）** | 191.0cm × 95.5cm | 京都・大阪など関西・西日本全般 | 最も大きい。「本間」とも呼ばれる。 |
| **中京間（ちゅうきょうま）** | 182.0cm × 91.0cm | 愛知・岐阜など中京地域、東北・北陸の一部 | 「三六間（さぶろくま）」とも呼ばれる。 |
| **江戸間（えどま）** | 176.0cm × 88.0cm | 関東一帯、東北、北海道 | 「五八間（ごはちま）」「関東間」とも呼ばれる。現在最も普及。 |
| **団地間（だんちま）** | 170.0cm × 85.0cm | 全国の集合住宅・公団住宅 | 「五六間（ごろくま）」とも呼ばれる。最も小さい。 |

### 6畳の面積比較

| 規格 | 6畳の面積（約） |
|------|----------------|
| 京間 | 10.94 m² |
| 中京間 | 9.93 m² |

## 4-2. 畳の敷き方（配置）ルール

> 画像・図版作成や和室の説明時に必須の作法。**一般住宅・店舗ブランド用途では「祝儀敷き」が正解**。AI画像生成では格子（碁盤目）状に並べる誤りが頻発するため要注意。

### 4-2-1. 祝儀敷き（しゅうぎじき）＝一般住宅の標準

- **隣り合う畳の合わせ目を「十字（＋）」にしない**＝**畳の四隅が1点に集まらない**ように敷く。
- 継ぎ目はすべて **T字** になり、全体は **卍（まんじ）状・風車状に回転** した配置になる。
- 結婚など祝い事で用いられてきた縁起の良い敷き方。**現在の一般和室はほぼこれ**。
- 実用面でも、四隅が集中する格子は角が傷みやすく、T字配置は摩耗を分散できる。

### 4-2-2. 不祝儀敷き（ぶしゅうぎじき）＝避けるべき

- 全部同じ向きに **碁盤の目（格子）状** に並べ、**合わせ目が十字に交差** する敷き方。
- **葬儀・寺院・旅館の大広間など限定**の特殊な敷き方。
- **一般住宅・畳屋のブランド画像でこれを描くのはNG**（=素人っぽく・縁起も悪く見える）。

```
× 不祝儀敷き（格子・四隅が＋）        ○ 祝儀敷き（T字・卍状）
┌──┬──┬──┐                      ┌─────┬─────┐
├──┼──┼──┤  ← 四隅が十字に交差    │  横   │  横  │
└──┴──┴──┘                      ├──┬──┴──┬──┤
                                 │縦│  横   │縦│
                                 └──┴─────┴──┘
```

### 4-2-3. 部屋サイズ別の正しい敷き方（祝儀敷き）

| 畳数 | 敷き方 |
|------|--------|
| **6畳** | 奥に横向き2枚 → 左右に縦向き1枚ずつ → 中央に横向き2枚（上下）。※全部横並びは不祝儀敷きになるので不可。 |
| **4畳半** | 中央に **半畳1枚**、その周りを4枚が **風車状に90°ずつ回転** して囲む。 |
| **8畳・10畳** | 同様に卍状へ展開し、四隅が1点に集まる箇所を作らない。 |

```
4畳半（中央＝半畳、周囲4枚が風車状）
┌──────┬────┐
│  ①横  │    │   ①上＝横, ②右＝縦,
├───┬──┤②縦 │   ③下＝横, ④左＝縦,
│   │半├────┤   中央＝半畳
│④縦│畳│    │
│   ├──┤③横 │
└───┴──┴────┘
```

### 4-2-4. その他の作法

- **半畳の位置**：鬼門（北東）を避ける。
- **床の間**：床の間の前の畳は **床の間と平行** に敷く（縁が直角に突き当たる敷き方は失礼）。
- **目の向き**：出入口から見て **畳の目が進行方向** になるよう、入口と畳を平行に。全室で目の向きを揃える。

## 5. 畳のお手入れ方法

### 5-1. 日常のケア

- **掃除の基本**: 畳の目に沿ってほうきで掃くか、掃除機をかける。目に逆らうと畳表を傷める原因になる。
- **掃除機のかけ方**: ブラシの回転を停止し、畳の目に沿ってゆっくりと吸い取る。強く押し付けない。
- **拭き掃除**: 乾拭きが基本。水拭きは畳を湿らせカビの原因となるため、頻繁に行わない。水拭きする場合は固く絞った雑巾で、必ず目に沿って拭く。
- **換気**: 天気の良い日は窓を開けて風を通す。湿気がこもらないようにする。
- **家具の跡**: 重い家具の下には当て板を敷いて凹み防止。

### 5-2. カビ対策

**発生原因**: 高温多湿（湿度70%以上、温度20〜30℃）、換気不足、新しい畳表（い草の栄養分が豊富なため）。

**予防方法**:
- 毎日の換気が最も重要。
- 室内の湿度を60%以下に保つ（除湿機やエアコンのドライ機能を活用）。
- 畳の上に布団を敷きっぱなしにしない。
- 新しい畳は特に梅雨時期の湿度管理を徹底する。

**発生した場合の対処**:
1. まず窓を開けて換気し、畳を乾燥させる。
2. 乾いてから掃除機でカビを吸い取る（目に沿って）。
3. 消毒用エタノール（アルコール）を布に染み込ませ、畳の目に沿って拭く。
4. 乾拭きで仕上げ、十分に乾燥させる。
- **注意**: 重曹は畳を変色させるため使用しない。塩素系漂白剤も畳を傷める。

### 5-3. ダニ対策

**発生原因**: 高温多湿、埃や食べかす（ダニの栄養源）、換気不足。

**予防方法**:
- こまめに掃除機をかける。
- 室内の湿度管理（60%以下に保つ）。
- 畳の部屋での飲食を控える。

**駆除方法**:
- ダニは夜行性のため、部屋を1時間程度暗くしてから掃除機をかけると効果的（ダニが表面に出てくる）。
- ダニは乾燥と高温に弱い。60℃以上の熱風で駆除可能（布団乾燥機の活用）。
- 天日干しも有効。

### 5-4. 素材別の注意点

- **天然い草**: 調湿性があるが、カビ・ダニの発生リスクも高い。換気・湿度管理が必須。
- **セキスイ美草・ダイケン健やか表**: カビ・ダニの発生リスクは低い。水拭き可能でメンテナンスが容易。

## 6. 畳の歴史（簡潔年表）

| 時代 | 畳の位置づけ |
|------|-------------|
| **古代（古事記・奈良時代）** | 「畳」の語が古事記に初出。菅や皮を重ねた敷物を指した。正倉院に現存する「御床畳（ごしょうのたたみ）」は聖武天皇が使用したもので、現存最古の畳とされる。い草の菰を使い、錦の縁が付けられていた。 |
| **平安時代** | 寝殿造の貴族邸宅で、板敷の上に座具・寝具として畳を「置いて」使用。身分・地位によって畳の厚さや縁の柄が異なり、権力の象徴として機能した。部屋全体には敷き詰めず、必要な場所にのみ配置。 |
| **鎌倉〜室町時代** | 書院造の成立に伴い、部屋全体に畳を敷き詰めるスタイルが定着。小部屋割りが行われ、畳が建築モジュールの基準となっていった。 |
| **安土桃山〜江戸時代** | 茶道の発展とともに茶室で畳が重要視される。数寄屋造りの普及。江戸時代中期以降、一般庶民にも普及。「畳師」「畳屋」という専門職が確立。徳川幕府には「畳奉行」という役職も存在した。 |
| **明治〜昭和** | 住宅の洋風化が進む中でも、和室の畳は日本住宅に不可欠な存在として維持。高度経済成長期には大量生産体制が整う。 |
| **現代** | 和紙畳や樹脂畳など新素材の登場。カラー畳やヘリなし畳（琉球畳風）など、モダンなインテリアに合うバリエーションが増加。国産い草の主産地は熊本県（国内シェア約93%）。 |
