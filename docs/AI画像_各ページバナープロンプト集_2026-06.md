# パターンA：背景帯（文字なし）

## 使い方

- **全部 16:9** で生成 → ヘッダー帯に `background-size:cover` でトリミング表示（**上下が切れる前提**）。
- 各ページは「**共通ベース** ＋ 下の**ページ行**（絵柄）」を1プロンプトに連結して生成。
- **文字は入れない**（タイトル・リード文はHTML側で重ねる＝崩れ・修正リスクなし）。
- モデルは **gpt-image-2 / 16:9 / 2K / `--n 3〜4`**（文字を焼かないのでgeminiの文字精度は不要、作り込みと複数案に強いgpt-image-2が最適。プレイブック「新規作り込み=gpt-image-2」）。
- 候補は `99_image_output` に出して選別 → 採用分だけ `images/` へ（旧版は `images/old/` 退避）。気に入った1枚の微調整は `gemini-3.1-flash --image`。

## 🎯 背景帯のいちばんのコツ（可読性設計）

1. **被写体は左右の端・または下寄り**に置き、**中央〜上部は淡くすっきりした余白**にする（ここに見出しが乗る）。
2. **上下端には重要物を置かない**（cover表示で切れる）。重要な被写体・余白は**左右方向**に配置する。
3. **全体は明るめ・低コントラスト**。後段でHTML側に生成り色の薄ベールを重ねるので、画像自体も**白っぽく軽い**トーンが扱いやすい。

## 実装メモ（HTMLへの敷き方）

- 対象は各ページの `<section class="page-header" ...>`（price/flow/goods/tatami/works/about/contact/voice）と `<section class="hero">`（line-lp/line-mitsumori）。
- 背景差し替え＋**文字可読性のため生成り色の薄ベールを重ねる**：
  ```css
  background-image:
    linear-gradient(rgba(250,248,245,.80), rgba(250,248,245,.55)),
    url("images/banner_price.webp");
  background-size: cover;
  background-position: center;
  ```
- 写真版では**既存の六角SVG柄は外す**（写真と競合・装飾2種ルール）。
- 高さの目安：PC `min-height:300px` 前後／SP `min-height:180px` 前後。テキストは縦中央寄せ。
- ファイル名案：`images/banner_<page>.webp`(+`.jpg`)。差し替え時は旧版を `images/old/` へ退避（既存ルール）。
- 装飾背景なので `alt` は空でOK。CLS対策に高さ（min-height/aspect-ratio）を必ず指定。

# パターンB：文字入りバナー（タイトル焼き込み）

> 画像にページ名（短い見出し）を焼き込む版。コラムサムネと同じ作り方。見栄えは強いが、**文言を直すたび再生成**が必要。

## 使い方・パターンAとの違い

- **モデルは gemini-3.1-flash 推奨**（日本語の文字を誤字なく描ける。プレイブックで実証）。`--n` が効かないので複数案は **コマンドを複数回** か **gpt-image-2** で。16:9 / 2K。
- 「」内を**一字一句正確に**。**送り仮名は「お見積もり」**。NG語（即日対応・コミコミ・一切/絶対/必ず・古畳処分=無料/込み・自社一貫製造）は焼かない。
- **文字は太字＋白フチ（または濃い緑文字＋明るい地）で大きく**、左右・中央の安全域に置く（**上下端は切れるので文字を置かない**）。
- 焼くのは**メイン見出し1本**が基本（崩れにくい）。サブを足すなら**短い1行**まで。
- レイアウト：**見出しを片側（左 or 中央）／ビジュアルを反対側**（コラムサムネと同じ構図）。

## 実装メモ（文字入り版の注意）

- 画像にタイトルが焼かれるため、HTMLの `<h1>`・リード文と**二重**になる。対処：
  - **推奨**：画像をヘッダーに敷き、HTMLの `<h1>` は **`visually-hidden`（画面外）** にしてSEO/読み上げ用に残す（文言は画像と一致させる）。リード文・ボタンは画像の下に通常表示。
- 文字入りは**文言修正＝再生成**。料金・キャッチなど変わりやすい文言は焼かず、パターンA＋HTML文字が無難。
- ファイル名案：`images/banner_<page>_text.webp`(+`.jpg`)。パターンAと別名で共存。
