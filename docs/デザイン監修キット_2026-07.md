## Part 2. 診断 ─ 7つの「揺らぎ」（数値根拠つき）

積み上げ式に80ステップ超で作ったため、**細部のリズムに揺らぎ**が出ている。重要度順：

| # | 揺らぎ | 数値根拠 | 効き |
|---|--------|---------|------|
| 1 | **タイポスケール未体系化** | font-size が 0.6〜1.75rem で**20種以上**乱立。特に0.7〜0.9remの小サイズ帯に微妙違いが密集 | ★★★ 最優先 |
| 2 | **余白リズムの乱れ** | padding/margin/gap に 14・18・26・36px など**8pxグリッド外の値が多数**混在（8px系: 8/16/24/40と、外れ値が拮抗） | ★★★ |
| 3 | **金アクセントが眠っている** | `--accent` 使用12回 vs `--main` 46回。**老舗の格を出せる金をほぼ使えていない** | ★★★ |
| 4 | **影(box-shadow)が8種バラバラ** | 濃さ0.04〜0.2・ぼかし8〜30pxが混在。カードごとに影が違い**安っぽく見える温床** | ★★ |
| 5 | **見出しジャンプ率が弱い** | h2=1.75remどまり。セクションの"つかみ"が弱く、スキャン時に階層が読み取りにくい | ★★ |
| 6 | **インラインstyleの氾濫** | index.html だけで**81箇所**。一回性スタイルがリズムを乱し、横展開・保守を困難に | ★★ |
| 7 | **和文タイポの原則が未適用** | 見出しは詰め気味・本文は広め、句読点アキ、禁則——といった和文組版の作法が体系化されていない | ★ 上質化の総仕上げ |

## Part 3. Fable 5への監修依頼（優先順位 1→2→3）

**Fable 5に判断してほしいのは「数値では決まらない、美的センスの要る問い」。** 下の観点で方向を出してほしい。実装・検証・70ページ展開・ブランド事実チェックはOpus(私)が引き取る。

### 🥇 優先1：トップページ（index.html）
最も見られるページ。ここの品質を上げて他ページへ横展開する。
- **FVの第一印象**：老舗75年の「格」と「親しみ」のバランス。今のスライド3枚＋バッジ＋見出しの構成で情緒は足りているか。横内さんのプロ写真が主役に入る前提でのレイアウト設計
- **金アクセントの効かせどころ**：どこに絞って使えば「高級感」が出て、どこは使わない方が上品か（診断#3）
- **視線誘導**：FV→悩み→選ばれる理由→数字→料金→お客様の声→コラム、の流れで一番見せたい情報への導線は最短か
- **セクション間の"呼吸"**：詰まって見える／間延びして見える箇所の指摘（診断#2）

### 🥈 優先2：デザインシステム全体（style.css）
トップで決めた方向を、全70ページの土台に落とす。
- **タイポスケール**：Part4の叩き台（8段階）でジャンプ率・可読性は適切か。和文としての詰め方針（診断#1,5,7）
- **余白スケール**：8pxグリッド化の是非と、セクション/カード/本文それぞれの標準余白
- **影の3段化**：sm/md/lg の3段に絞る際の各値（診断#4）
- **金の役割定義**：システムとして金をどう位置づけるか（区切り線・見出し装飾・数字強調・ボタン縁 など）

### 🥉 優先3：コラム記事の見た目
新規50記事＋既存で計90本超。読み物としての質を底上げ。
- **本文の可読性**：行長・行間・段落間、見出しと本文のコントラスト
- **図解・サムネ・本文画像のトンマナ統一**（AI画像250枚が入る前提。[AI画像_運用プレイブック](AI画像_運用プレイブック_2026-05.md)準拠）
- **関連記事・CTA・ポイントボックス**の視覚的な役割分担

## Part 4. Opusの叩き台（Fable 5がYES/調整するための素案）

Fable 5がゼロから考えなくて済むよう、**数値で決まる部分は私が素案を用意**。これを叩いて／承認してもらう前提。

### タイポスケール案（8段・rem）
```
--fs-xs:   0.75rem   /* 注記・キャプション */
--fs-sm:   0.875rem  /* 補助テキスト */
--fs-base: 1rem      /* 本文 */
--fs-md:   1.125rem  /* リード・強調本文 */
--fs-lg:   1.375rem  /* h3 */
--fs-xl:   1.75rem   /* h2 */
--fs-2xl:  2.25rem   /* h1・セクション主見出し */
--fs-hero: 2.75rem   /* FV見出し */
```
※和文なので欧文の1.25倍比より**ジャンプ率をやや強め**に。見出しは`letter-spacing: 0.04em`＋やや詰め、本文は標準。

### 余白スケール案（8pxグリッド）
```
--sp-1: 4px   --sp-2: 8px   --sp-3: 16px  --sp-4: 24px
--sp-5: 32px  --sp-6: 40px  --sp-7: 48px  --sp-8: 64px
```
セクション縦：モバイル`--sp-6`/PC`--sp-8`、カード内：`--sp-4`、本文段落間：`--sp-3` を標準に。

### 影スケール案（3段）
```
--shadow-sm: 0 2px 8px rgba(0,0,0,0.05)    /* カード通常 */
--shadow-md: 0 4px 16px rgba(0,0,0,0.08)   /* ホバー・浮き */
--shadow-lg: 0 8px 30px rgba(0,0,0,0.12)   /* モーダル・追従バナー */
```

### 金アクセントの運用案（診断#3への回答叩き台）
- 使う：セクション区切りの短い線、見出し脇の装飾、「数字で見る」の数字、CTAボタンの細い縁取り、引用・ポイント枠の左罫
- 使わない：広い面の塗り、本文リンク、多用（1画面2〜3箇所まで）
