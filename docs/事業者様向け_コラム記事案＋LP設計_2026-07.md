## 0. 方針（合意事項）

- サイトの主役は **個人のお客様向け**。トップページのメニューには業者向けを出さない。
- 業者は「**業者向けコラム記事**（検索流入・情報提供）」を入口にし、記事の締めから
  「**事業者様向けLP**（取引条件・問い合わせ）」へ送る導線をつくる。
- LP は **noindex にしない**（検索でも拾えるようindex対象／トップ導線に出さないだけ）。
- キーワードは個人向けページと食い合わせない（業者側の検索語を狙う）。

```
【入口】業者向けコラム（検索流入）
      ↓ 記事末の一文リンク
【受け皿】事業者様向けLP（business_draft.html → 将来 business.html）
      ↓
   お問い合わせ（電話 / LINE / contact.html）
```

## 2. 業者向けコラム記事案（優先順）

個人向けと**キーワードがかぶらない**業者検索語を各記事に設定。各記事は末尾でLPへ送客。

| No | 記事タイトル（案） | 主なターゲット | 狙うキーワード例 | 状態 |
|----|-------------------|---------------|-----------------|------|
| B1 | 賃貸の退去・入居で畳は「表替え」と「新調」どっちが得か | 賃貸管理会社・オーナー | 賃貸 畳 表替え 新調 費用 / 原状回復 畳 | 既存chintaiを補強＋LP導線でほぼ即対応可 |
| B2 | 工務店・リフォーム会社向け｜和室/小上がりの畳仕様の決め方 | 工務店・リフォーム・内装 | 畳 仕様 工務店 / 小上がり 畳 施工 / 縁なし 畳 納まり | 新規 |
| B3 | まとまった枚数・短納期の畳発注に対応できる畳店の選び方 | 内装業者全般・元請 | 畳 大量発注 / 畳 短納期 / 畳 業者 まとめて | 新規（1日40枚が主役） |
| B4 | 旅館・飲食・施設の畳メンテナンス｜張替え頻度と費用の目安 | 旅館・飲食（座敷）・介護 | 旅館 畳 張替え 頻度 / 店舗 畳 メンテナンス | 新規 |
| B5 | 賃貸オーナーの空室対策｜畳替えの投資対効果を畳屋が正直に | 賃貸オーナー | 空室対策 畳 / 入居率 畳替え | 新規（chintai節を独立記事化） |

各記事の共通構成:
1. リード（業者の困りごとを1つに絞る）
2. 判断基準・相場・納期などの**実務情報**（表を1つ入れる）
3. 「大浜畳商店の場合」= 1日40枚・三代の供給力を1段落
4. **記事末CTA**:「まとまった枚数・継続でのご相談は〈事業者様向けのご案内〉をご覧ください →」でLPへ
   ※記事途中には貼らず、読み終えた業者だけが進む形。

運用ペース: 既存のブログ運用（月10〜15本）に**業者向けを月1本**混ぜる程度から。

## 4. 大浜さんに要確認（公開前の必須チェック）★

LP内に条件系を書いているが、**事実確認が取れるまで本番に出さない**。以下を6/3 or 次回MTGで確認:

1. **請求書払い・掛け払い（月締め等）に対応するか？** 締め日・支払サイト。
2. **法人・継続取引の最小ロット/最小金額はあるか？**（例：1枚から？◯枚以上？）
3. **短納期はどこまで可能か？**（例：最短◯日、繁忙期の目安）
4. **対応エリアは業者取引でも個人と同じか？**（遠方の元請対応の可否）
5. **許可番号など掲載してよい登録情報**（あれば）。
6. そもそも **業者取引をどれくらい増やしたいか**（力の入れ具合＝LPの作り込み度を決める）。

→ 未確定の項目はLP側で「ご相談ください」表現に留めている。確定後に具体値へ差し替え。
