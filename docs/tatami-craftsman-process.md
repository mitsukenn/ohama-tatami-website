# 畳職人の仕事と畳製造工程リファレンス

大浜畳商店（長崎市・創業75年・社長42歳・職人歴20年）のブログ執筆時に使える、畳製造工程の基礎知識リファレンス。信頼できる業界情報源（熊本県畳工業組合、京都府公式、各地の老舗畳店公式サイト等）をもとにまとめています。

---

## 1. 畳の基本構造

畳は大きく「畳床（たたみどこ）」「畳表（たたみおもて）」「畳縁（たたみべり）」の3つのパーツから成り立っています。

### 1-1. 畳床（たたみどこ）— 畳の「芯」

畳の内部にあたる土台部分。畳の弾力性・断熱性・保湿性・吸音性を決定する最重要パーツです。伝統的な「藁床（わらどこ）」は稲わらを何層にも積み重ね、約5cmまで圧縮して縫い上げたもの。現代では藁サンドイッチ床（藁＋建材）、建材床（インシュレーションボード＋ポリスチレンフォーム）などが主流です。

**仕入れ形態：** 畳床は専門の畳床メーカー・材料屋から仕入れるのが業界の標準。藁床を自社で製造する畳店は全国でもごくわずかで、中規模畳店（大浜畳商店もこのカテゴリ）では原則として材料屋仕入れです。

### 1-2. 畳表（たたみおもて）— イグサを織った「ござ」

経糸（たていと）にイグサを織り込んだ表面材。イグサの品質・長さ・本数・産地（熊本県産、中国産など）で等級が決まります。織るのに1枚あたり約90分かかります。

**仕入れ形態：** 畳表はイグサ農家または問屋から仕入れ。織り工程は農家・織元が担い、畳店は仕入れた畳表を畳床に張り付ける工程を担当します。

### 1-3. 畳縁（たたみべり）— 長辺の装飾布

畳の長辺に縫い付ける布帯。畳表の切り口を隠すと同時に、畳表を畳床に縫い留める構造的役割も果たします。綿・麻・化繊・紋縁など種類豊富で、部屋の格や好みで選びます。

**仕入れ形態：** 畳縁メーカーから仕入れ。

> 参考：[熊本県畳工業組合](https://www.tatami-kumamoto.com/knowledge/finished)／[京たたみ匠・もとやま畳店](https://kyo-tatami.com/about/)

## 2. 畳職人が行う工程（表替え・新畳）

畳店の仕事は大きく「新畳（しんたたみ）＝丸ごと新調」「表替え（おもてがえ）＝畳表と畳縁の張替え」「裏返し＝畳表を裏返して使う」の3種類。ここでは中核となる工程を解説します。

### 2-1. 採寸（さいすん）

お客様宅を訪問し、部屋の寸法を1mm単位で実測する工程。設計図の寸法通りに作ってもピッタリ合うことはまずなく、壁の反り・柱の出っ張り・直角でない角などの誤差を現場で吸収するため必須です。「部屋の設計図があるのになぜ採寸？」とよく聞かれますが、建物は人が作るものでミリ単位の歪みが必ずあるためです（[もとやま畳店](https://kyo-tatami.com/saisun/)）。

### 2-2. 畳床の準備

新畳なら新しい畳床を仕入れ、表替えなら既存の畳床を工房に持ち帰って再利用します。古い畳表・畳縁を外し、畳床の反り・へたりを点検・補修します。

### 2-3. 框（かまち）縫い

畳の短辺側＝頭側（框）に、新しい畳表を合わせて縫い付ける工程。片側を引っ張りながら縫うことでたるみを防ぎます。畳のハリと耐久性を決める最も重要な工程のひとつ。

### 2-4. 平刺し（ひらざし／平縫い）

畳縁を畳本体に縫い付ける工程。畳と平行に、畳縁と下紙（したがみ）を縫っていきます。下紙を入れることで畳縁の劣化を防ぎます。使用する針は「刺し針 4寸5分（約13.6cm）」。現代では「手縫いの畳」と言っても、平刺しだけは機械で行うのが一般的です。

### 2-5. 返し（かえし／返し縫い）

平刺しで縫い付けた畳縁を、側面に折り返して縫い留める工程。畳の厚みに合わせて糸の張りを調整しながら引っ張って縫うことで、畳縁がピンと張った美しい仕上がりになります。使用する針は「返し針 5寸2分（約15.8cm）」。框縫い・返し縫いの際に藁を充てて縫い締めることで、畳のしなりが消え、ピンと引き締まり型崩れしない畳になります。

### 2-6. 隅（すみ）縫い・仕上げ

四隅の角を補強する縫製、表面の磨き、最後の検品。泥や糸くずを落として納品準備完了。

### 縫い工程まとめ
畳縫いは伝統的に **①框縫い → ②平刺し → ③返し縫い → ④隅縫い** の4工程で構成されます（[菱屋畳 佐竹商店](https://kyoto-tatami.com/tips/process.htm)／[中久畳店](https://www.nakahisa-tatami.com/original5.html)）。

### 2-7. 納品・敷き込み

工房で仕上げた畳を現場に運び、1枚ずつ合わせて敷き込み、段差や隙間を微調整します。

## 3. 機械化と手作業

### 3-1. 現代の主流は機械製作

現在、畳の製作工程の約95%は畳縫着機（自動製畳機）を使った機械製作です。東海機器工業、KLASS（旧極東産機）などのメーカーが畳縫着機・自動裁断機を供給しています。

### 3-2. 手縫い（手刺し）と機械縫いの違い

| 項目 | 手縫い（手刺し） | 機械縫い |
|---|---|---|
| 縫い方 | 畳表だけを引っ張って縫う | 畳表と畳床をまとめて縫う |
| ハリ | 張りの良い仕上がり | やや劣る |
| 耐久性 | 数十年使っても型崩れしにくい | 経年で形が崩れやすい傾向 |
| 所要時間 | 1枚に数時間〜 | 1枚あたり数十分 |
| 価格 | 高級品・特注 | 標準品 |

手縫いは糸締めの力加減を素材に合わせて調整できるため、経年後の型崩れが起きにくく長く美しい姿を保ちます（[金井畳店](https://www.tatamiya-kanai.com/service/tatami-tenui/)）。

### 3-3. 中規模畳店（大浜畳商店のような店）の典型スタイル

- 畳床は材料屋仕入れ、畳表・畳縁も問屋仕入れ
- 框縫い・平刺しは畳縫着機を使用、返し縫いや難所は手で仕上げる「機械＋手仕上げ」のハイブリッドが主流
- 1人の職人が 1日あたり 6〜10枚（平常時）／**繁忙期は最大30〜40枚** をこなすケースあり
- 繁忙期：**年末（12月）**が最大、梅雨明け〜お盆前も需要集中
- 表替えの施工日数：1〜2日、新畳は3〜10日が目安（[川田畳製作所](https://kawadatatami.jp/1313/)）

## 4. お客様向けの表現（言い換え例）

職人目線の専門用語はお客様には伝わりにくいため、ブログやLP・チラシでは言い換えが有効です。

| 業界用語 | お客様向け言い換え例 |
|---|---|
| 採寸 | 「お部屋の寸法を1枚ずつお測りします」「ミリ単位で現場確認」 |
| 框（かまち）縫い | 「畳の頭を合わせて縫い留める工程」 |
| 平刺し／返し | 「へり（ふちの布）を丁寧に縫い付ける仕上げ」 |
| 手刺し | 「一針ずつ手で縫い上げる伝統製法」 |
| 新畳 | 「畳まるごと新しく」「まるごと新調」 |
| 表替え | 「畳の表面だけ新品に」「畳のおもてを張り替え」 |
| 裏返し | 「今の畳をひっくり返して再利用」 |
| 敷き込み | 「お部屋にピッタリ合わせて敷く仕上げ作業」 |

### 価値訴求のコツ
- 「採寸」→ 「ミリ単位で測りに伺うから、どんな歪みのあるお部屋でもピタッと収まります」
- 「手仕上げ」→ 「機械任せにせず、最後は職人の目と手で一枚ずつ仕上げます」
- 工程写真では「針」「糸」「職人の手」が主役。顔出しNGでも"手"は強い訴求素材（大浜畳商店の画像ルールに合致）

## 5. 畳業界の一般的慣習

### 5-1. 老舗畳店の歴史

- 江戸時代後期に「畳屋」「畳職人」が職業として確立
- 江戸中期以降、畳が庶民に普及
- 現存する最古級の畳店は **創業180年（宮城・愛畳工房 若柳）** など
- **創業50〜100年**の畳店は各地に多数。**創業75年の大浜畳商店は「地域の老舗」としては十分に訴求可能な歴史**

### 5-2. 職人1人あたりの1日仕上げ枚数の目安

- 平常時：表替えで6〜10枚／日
- 繁忙期（12月・お盆前）：1日30〜40枚をこなす畳店もあり（大浜畳商店の「繁忙期40枚」はまさにこの最上位水準）
- 手縫い専業の高級畳では1日1〜2枚ということも

### 5-3. 創業年数・職人歴の訴求表現例

- **創業75年** → 「三代続く」「親子三代、長崎の畳を守り続けて75年」「戦後間もなくの開業から地域のお座敷を守る」
- **職人歴20年** → 「20年、畳一筋」「針と糸に向き合い続けて20年」「中堅職人として最も脂の乗った世代」
- **繁忙期40枚** → 「年末は1日40枚の畳を仕上げる繁忙期。長崎のお正月を畳で迎えるために」
