Section 01

戦略の前提：誰に・何を・どうするか

「勝てるHP」の最上位概念。デザインやSEOの前に、この3つが明確でなければ何を作っても意味がない。

コアターゲット

長崎市在住、40代の共働き夫婦（妻が意思決定者）。築20年の戸建て。和室は6畳×2部屋。子どもは小学生。畳のささくれが気になり始めたが、どこに頼めばいいかわからない。チラシの激安業者には不信感がある。電話するのが面倒なので、まずLINEで相場を知りたい。重い家具の移動がネックで先送りしている。

誰に

「畳替えを検討しているが、業者選びに不安がある長崎市内の30〜60代の家庭」。中でも、初めて畳替えを依頼する層（スマホ検索 → 比較検討 → LINE or 電話）が最重要。

何を

USP（独自の売り）：「長崎駅前の畳屋が、写真1枚で無料診断。見積もりから納品まで同じ職人が担当します。」

3つの差別化軸：
① LINEで写真を送るだけで無料診断＋概算見積り（競合12社中1社のみ対応）
② 見積もり→採寸→施工→納品まで同一職人が一貫対応（大手チェーンとの決定的差異）
③ 朝お預かり・夕方お届け＋家具移動無料（行動障壁の完全除去）

どうするか

新PASONAの法則 ×「3つの壁」突破を構成原理としたWebサイトで、「検索 → 安心 → 問い合わせ」の最短導線を設計する。

壁突破方法該当ページ・要素
見ない壁 FVは信頼感で迎え入れ、直後の悩み共感セクションで感情に刺す二段構え トップFV（信頼）/ 悩み共感セクション（感情トリガー）
信用しない壁 社会的証明（お客様の声・施工実績）＋顔の見える安心感（代表写真・職人紹介） 施工事例 / お客様の声 / 会社概要 / 選ばれる理由
行動しない壁 行動の言い訳を提供。摩擦ゼロの導線（LINE・電話の2軸） CTA / お問い合わせ / 料金シミュレーター / 追従バナー

Section 03

トップページ：セクション設計とコピー案

新PASONAの法則に基づき、ユーザーの心理経路に沿った8セクション構成。各セクションがどの壁を突破するかを明示。

v1.1 設計原則：ウェブサイトとLPの温度感を分ける

LPは「一回きりの勝負」だから、感情を煽るコピーが有効。しかしウェブサイトは「何度も訪れる場所」であり、信頼感が土台にないと逆効果になる。

FV = 信頼感のある看板。「この店は安心できそうだ」と感じさせるトーン。
悩み共感セクション = 感情に刺すフック。スクロールした先で「自分のことだ」と引っかからせる。

この二段構えにより、信頼で迎え入れ → 共感で引き込む、というウェブサイトに適した心理導線を設計する。
① FV（ファーストビュー）─ 信頼感で迎え入れる

目的

「ちゃんとした畳屋だ」という信頼感を与え、安心してスクロールを続けてもらう。煽りではなく、品格のあるトーンで「何をしてくれる店なのか」を30秒以内に伝える。

方針

現行の「畳のことなら、大浜畳商店。」を維持する。
このコピーが持つ「堂々とした信頼感」「地に足がついたトーン」はウェブサイトのFVとして正しく機能している。LP的な煽りコピーに変更しない。ただし、このコピーだけでは「何をしてくれる店なのか」が伝わらないため、サブコピーと差別化バッジで補強する。

FV構成

メインコピー（現行維持）
畳のことなら、
大浜畳商店。
サブコピー案
朝お預かり、夕方にはお届けします。
家具の移動も、お見積もりも無料です。

差別化バッジ（3つ）

FV内にバッジとして視覚的に配置。「一目で何をしてくれる店かわかる」ための要素。

バッジ伝えること突破する痛み
家具移動無料重い家具を動かす必要がないこと面倒くさい → 先送り
LINEでお見積もり電話しなくていいこと電話のハードル
長崎駅前すぐ地元の信頼できる店であること業者選びの不安

CTA（2つ）

  • 「無料でお見積もり」（メインCTA → contact.htmlまたはLINE）
  • 「料金を見る」（サブCTA → #priceアンカーリンク）

背景画像

  • 実際の施工写真を使用（AI生成画像は絶対に使わない）
  • 候補：美しい仕上がりの和室 / 作業風景 / 縁なし畳のモダンな空間
② 悩み共感 ─ ここで感情に刺す

目的

FVの信頼感で「安心できそうだ」と感じた訪問者に対し、このセクションで「自分のことだ」と引っかからせる。ウェブサイト全体の中で、ここが最も感情強度の高いセクション。

キャッチコピー候補（セクション見出し）

FVではなくこのセクションの見出しとして使うことで、ウェブサイトの品格を保ちつつ感情トリガーを活かせる。

候補A：恥ずかしさ起点（SNS調査 恥ずかしさ系より）
その畳、お客さんに
見られても大丈夫ですか？
候補B：先送り起点（市場の痛み 第2位より）
「そろそろかな」と思ってから、
何年経ちましたか？
候補C：現行の穏やかなトーン（現状ベース）
こんなお悩み、ありませんか？
大浜さん確認事項：候補A〜Cのうち、大浜畳商店のトーンに合うものを選択。AまたはBを使う場合、ウェブサイトとしての品格は維持しつつ「自分ごと化」の効果が高まる。Cは無難だが刺さり方は弱い。

最後に「ひとつでも当てはまったら、まずはご相談ください。」で共感→行動への橋渡し。

③ 選ばれる理由 ─ 信用しない壁突破

目的

「なぜ大浜畳商店を選ぶべきか」の根拠を3つに絞って提示。

現状の評価

現在の3つ（朝預かり夕方届け / 同じ職人 / お部屋に合わせて）は内容として良い。ただし「同じ職人が担当」の価値が十分に伝わっていない。消費者が業者に対して抱く「営業と職人が違う人で話が伝わらない」「勝手に畳を持ち帰られた」という恐怖（SNS調査 怒り系）に紐づけると、刺さり方が変わる。

改善案

#タイトルサブコピー案突破する痛み
1 朝お預かり、夕方お届け。
家具の移動も無料です。		 お出かけ前にお渡しいただければ、帰宅時には新しい畳の部屋が待っています。タンスやベッドはそのままで大丈夫。私たちが移動します。 面倒くささ / 先送り
2 見積もりから納品まで、
ぜんぶ同じ職人が担当します。		 営業マンが来て、別の職人が施工する。大手ではよくある話です。当店は、お見積もり・採寸・製作・納品まで同じ職人が一貫して担当。「話が違う」は絶対にありません。 業者不信 / 強引営業恐怖
3 お見積もり金額が、
そのまま最終金額です。		 畳表代（畳床代）・施工費・家具移動・配送費など、必要な費用を明示してお見積もりします。あとから追加料金が発生することはありません。（横付け不可・対応エリア外は別途諸経費の場合あり。古畳処分は新畳の場合のみ別途） ぼったくり恐怖 / 価格不透明
④ 料金の目安 ─ 信用しない壁突破

目的

「いくらかかるか不安」を解消。ここで価格を見せることで、下層の料金ページへの導線も兼ねる。

掲載内容

  • 裏返し / 表替え / 新畳の3カテゴリの料金概要（1畳あたり最低〜最高）
  • 「6畳パックの参考価格」を目立つ位置に表示（具体金額が最も行動を促す）
  • 「詳しい料金表を見る」ボタン → price.htmlへ
  • 概算シミュレーター（現在sub.htmlにあるものを移植、またはiframe）
注意：現状のトップページの料金セクションは縁付き3グレード＋裏返しのカード表示で良い構成だが、シミュレーターがsub.htmlにしかない。トップページにもシミュレーターへの導線を設けるか、簡易版を埋め込むべき。
⑤ 施工事例ピックアップ ─ 信用しない壁突破

目的

ビフォーアフター写真で「視覚的な説得力」を提供。競合12社中、体系的なB/A事例を載せているのは1社のみ。

掲載内容

  • 最新3〜4件の施工事例をカードで表示（B/A写真・地域名・工事種別・費用）
  • 「施工事例をもっと見る」ボタン → works.htmlへ
最重要：現在このセクションはコメントアウトされている。施工写真の蓄積が始まるまでは、最低でもプレースホルダーではなく「準備中」と明示するか、セクション自体を非表示にする。ダミー画像の掲載は信頼を損なうため絶対NG。
⑥ お客様の声ピックアップ ─ 信用しない壁突破

目的

第三者の言葉で信頼を構築。競合12社中、顔写真付きのお客様の声を掲載している業者はゼロ。ここを押さえるだけで圧倒的な差別化。

掲載内容

  • 2〜3件のお客様の声（写真・地域名・年代・施工内容・感想要約）
  • 「お客様の声をもっと見る」ボタン → voice.htmlへ
収集の仕組み化：施工完了時に①写真撮影（畳＋お客様了承あれば顔写真）②アンケート用紙③Googleクチコミ投稿依頼（QRコード付きカード）──この3点セットを納品時のルーティンに組み込む。

Section 06

お客様の声ページ

競合12社中ゼロの「顔写真付きお客様の声」を実現する。これだけで市場唯一の存在になれる。

Section 08

会社概要・代表挨拶ページ

「どんな人が家に来るのか」を事前に見せることで、心理的抵抗を取り除く。

掲載要素

  • 代表（大濵健太郎）のプロフィール写真（作業着姿が望ましい。信頼感＋親近感）
  • 代表挨拶（200〜300字。「なぜこの仕事をしているか」のストーリー）
  • 会社情報（社名・所在地・電話・設立年・許可番号・資本金）
  • 長崎県知事許可 第012410号の表示（内装仕上工事業の信頼性を証明）
  • アクセスマップ（長崎駅前徒歩4分を強調）
差別化ポイント：「有限会社」であること（個人事業主が多い業界で法人格は信頼の証）、「長崎県知事許可」を持つ内装仕上工事のプロであること。これらは競合のほとんどが持たない客観的な信頼性指標。

行動しない壁の最終突破。摩擦ゼロの3導線。

3つの連絡手段を並列表示

手段ターゲット表示の優先度
LINE 30〜50代。電話が苦手。まず相場だけ知りたい層 最優先 LINEが最大のCV導線。友だち追加QRコード大きく表示
電話 60代以上。すぐに話したい層 第2 タップで発信。営業時間を明記
フォーム 夜間・営業時間外に問い合わせたい層 第3 入力項目は最小限（名前・連絡先・ご相談内容のみ）
フォーム設計の鉄則：入力項目は本当に必要なものだけ。住所・部屋数・畳数は見積もり時にヒアリングすればよい。フォームの段階で聞きすぎると離脱率が急上昇する（カート離脱率70%の調査データより）。

Section 12

実装優先度とロードマップ

全部を同時にやろうとしない。「最も効果が大きいものから」順に。

フェーズ1：最小公開セット 最優先

これがないと始まらない。公開の最低条件。

  • トップページ（FV改善 + 悩み共感 + 選ばれる理由 + 料金概要 + 流れ + CTA）
  • 料金・メニューページ（シミュレーター含む）
  • お問い合わせページ（LINE / 電話 / フォーム）
  • Googleビジネスプロフィールの最適化

フェーズ2：信頼構築の山を積む 1〜2ヶ月以内

施工が進むたびにコンテンツが増える仕組みをフェーズ1と同時に設計しておく。

  • 施工事例ページ（最低5件のB/A写真が揃った時点で公開）
  • お客様の声ページ（最低3件が揃った時点で公開）
  • 会社概要・代表挨拶ページ

フェーズ3：SEO・教育コンテンツ 3ヶ月以降

  • コラム記事5本の公開
  • い草グッズページ
  • 畳替えの流れページ（独立版＋FAQ15問）
最も重要なこと：フェーズ1の公開時点で「施工事例の写真撮影ルーティン」と「お客様の声の収集フロー」を必ず稼働させておくこと。HPは公開がゴールではなく、「証拠の山」を積み上げ続けることが成果を生む。
